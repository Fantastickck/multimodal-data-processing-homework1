# ДЗ 1 «Внимание своими руками»

Решение двух исходных ноутбуков. Персональный вариант второго ноутбука — **seed 42, три ошибки**. Для обучения и генерации также зафиксирован seed 42.

- [dz1-attention.ipynb](dz1-attention.ipynb): реализованы `split_heads`, `merge_heads`, `scaled_dot_product_attention`, `TransformerBlock.forward`; сохранены выводы проверок и объяснение применения маски.
- [dz1-bughunt.ipynb](dz1-bughunt.ipynb): исправлены ошибки, заполнена таблица, выполнены проверки, обучение, валидация и генерация.
- [REPORT.md](REPORT.md): механизм каждой ошибки и результаты эксперимента.
- [artifacts/](artifacts/): график, история потерь, сгенерированный текст, метрики и конфигурация среды.

В каждом ноутбуке прошли **17 из 17** исходных проверок. За 600 шагов потери обучающего батча снизились **3,1525 → 0,0288**, валидационные — **3,1556 → 0,0235**. Модель воспроизводит фразу обучающего корпуса.

## Запуск в бесплатном Google Colab

1. Загрузите `dz1-attention.ipynb` в Colab. Выполните все ячейки сверху вниз: в конце должно быть `пройдено 17 из 17`.
2. Загрузите `dz1-bughunt.ipynb`. В меню **Среда выполнения → Сменить среду выполнения** выберите GPU T4. Ноутбук автоматически выбирает CUDA, если она доступна; также поддерживается CPU.
3. Выполните все ячейки сверху вниз. После `17 из 17` начнется обучение на 600 шагов. График и генерация появятся в следующих ячейках, файлы — в папке `artifacts` рабочей среды Colab.
4. Сохраните оба ноутбука с результатами выполнения и скачайте папку `artifacts` через панель файлов Colab.

В Colab используются предустановленные PyTorch и matplotlib. Данные создаются в ноутбуке. `requirements-lock.txt` фиксирует локальную CPU-среду и для Colab не нужен.

## Воспроизведение локально

Для локального запуска на CPU среда следующая: Python 3.12.3, PyTorch 2.9.0+cpu, [requirements-lock.txt](requirements-lock.txt). Основные результаты получены в Colab на T4.

Из корня проекта, при установленном `uv`:

```bash
uv venv .venv --python python3
uv pip install --python .venv/bin/python -r requirements-lock.txt
.venv/bin/python -m ipykernel install --prefix .venv --name homework1 --display-name 'Python (homework1)'
```

Если Python установлен с поддержкой `venv` и `pip`, устанавливать так:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt
```

После установки откройте оба ноутбука в VS Code или Jupyter, выберите Python из `.venv` и выполните ячейки сверху вниз.

## Эксперимент и воспроизводимость

Использованы настройки исходной обучающей ячейки: `context_size=64`, `d_model=128`, `n_heads=4`, `n_layers=2`, `d_ff=512`, `dropout=0.1`, батч 32, AdamW, learning rate `3e-4`, weight decay `0.01`, 600 шагов. Сохраняются все 600 значений cross-entropy и оценка train/validation без dropout до обучения и через каждые 100 обновлений.

Корпус — `'алгоритм внимания смотрит на все позиции сразу. ' * 200`. Первые 90% символов используются для обучения, последние 10% — для валидации. Повторение одной фразы позволяет проверить усвоение шаблона, но не обобщение на новые тексты.

Seed 42 устанавливается перед обучением и генерацией. Включены детерминированные алгоритмы, для оценки используются фиксированные батчи. На других версиях библиотек и устройствах результаты могут отличаться. Прогон выполнен в Google Colab на Tesla T4: Python 3.13.16, PyTorch 2.11.0+cu130, matplotlib 3.10.0. Конфигурация записана в [environment.json](artifacts/environment.json).
